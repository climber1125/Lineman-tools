⚡ Lineman Training Tools

Classroom tools for pre-apprentice linemen. Tap a green button to open one.

How to use this page
  1. Find the tool you want below.
  2. Tap the big green Open button. It opens in your web browser — nothing to install, no login.
  3. To project it, open it on the classroom computer and press F11 for full screen (press F11 again to exit).
  4. Only need one tool? Tap Copy link on it and text or email just that link.
  5. No internet in the room? Tap Save copy ahead of time. Double-click the saved file later and it works offline.
